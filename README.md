# **GitHub Activity CLI**

A simple Node.js CLI tool that fetches and displays the recent GitHub activity of any user — using only core Node modules.

## **Usage**

```bash
github-activity <username>
```

Example:

```bash
github-activity harshgharsandiya
```

## **Features**

-   Fetch recent GitHub events
-   Display readable activity (push, stars, issues, PRs, etc.)
-   No external libraries
-   Handles invalid users & API errors

## **Install (local development)**

```bash
npm install
npm link
```
